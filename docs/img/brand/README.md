# BETTA OS logo

`BETTA-OS.jpg` is the current 370 × 340 color logo used by the project README
and documentation header. The panel displays the same artwork at RGB565
color depth during startup and firmware updates. The conversion tool lives at
`tools/generate_brand_logo.py` in the repository.

`BETTAOS.jpg` is the original cyan logo inherited from the
[cptkirki/BETTA-HA-PANEL](https://github.com/cptkirki/BETTA-HA-PANEL) repository
at the fork baseline `420df764` (v0.8.2). Original project attribution: Cpt_Kirk.
It was moved from `images/BETTAOS.jpg` so published documentation assets live
under `docs/img/`.

The legacy upstream widget screenshots are no longer part of the published
documentation. Current dashboard and editor screenshots are in
[Examples](../../features.md).
